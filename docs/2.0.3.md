# 2.0.3 — 기세와 OVERDRIVE

게이머·연출 담당과 논의하여 연속 줄 제거의 콤보와, 한 도전 전체에 쌓이는 기세를 분리했습니다. 기세는 **연출 전용이며 피해량을 올리지 않습니다.** 보스 체력·방해 행·난수·공격 주기 규칙은 유지됩니다.

## 기세 규칙과 예시

- 줄을 지운 블록 고정마다 +1입니다. 1줄과 4줄 모두 +1이며, 여러 능력이 함께 발동해도 중복으로 쌓이지 않습니다.
- 줄을 못 지우거나 기다리거나 콤보가 끝나도 줄어들지 않습니다. 구역을 깨고 다음 전투로 넘어가도 유지됩니다.
- 사망·새 도전·이전 구역 보조 재도전은 0에서 시작합니다. 재도전의 능력 선택 화면은 기세를 주지 않습니다.
- 1 / 4 / 8 / 12에서 FOCUS / SURGE / BURST / OVERDRIVE가 됩니다. 12 이후에도 수치는 계속 쌓이고 연출 강도는 최고 단계로 유지됩니다.
- 예: 1줄 제거 → 빈 고정 → 2줄 제거라면 콤보는 다시 시작하지만 기세는 2입니다. 그 상태로 구역을 깨도 다음 구역의 기세는 2입니다.

## 빌드의 성공을 읽는 방법

HUD에는 최근 성공 이유를 표시하고, 공격 색과 형태에 빌드 특성을 반영합니다. 기세 획득량은 모든 빌드에서 같게 두어 특정 공격 방식이 과도하게 유리해지지 않도록 했습니다.

| 빌드 | 성공 표현과 예시 |
|---|---|
| 1줄 / 2·3줄 / 4줄 강화 | 실제 제거한 줄 수에 맞는 강화 표시. 1줄은 날카로운 탄, 2·3줄은 합쳐지는 탄, 4줄은 큰 코어와 위성탄 |
| 연쇄 / 연쇄 보호 | 연속 줄 제거의 성공은 연쇄 공격으로 표시. 콤보 종료와 기세 유지 안내를 분리 |
| 선제 타격 | 첫 두 번의 줄 제거에 선제 타격 표시 |
| 저층 / 고층 | 해당 높이 조건을 만족해 지운 경우 표시 |
| 전하 | 쌓인 전하를 줄 제거로 방출했을 때 충전 방출 표시. 기다리거나 빈 고정만 해서는 기세 획득 불가 |
| 방해 행 정리 | 실제 방해 행 복구가 함께 일어났다면 방해 행 복구 표시 |
| 방해 행 차단 | 실제 차단 성공 시 방어 색과 차단 안내로 갱신. 기세를 한 번 더 주지는 않음 |
| 착지 보조 | 단독 보조 빌드에서도 줄 제거 시 착지 보조 빌드로 표시. 착지·이동만으로는 획득 불가 |

## 연출

기세 단계에 따라 보드 밖의 왕관·옆 날개·공전 장식·불꽃이 커집니다. 공격에는 확대된 코어, 잔상, 위성탄과 겹치는 충격파를 추가했습니다. 높은 단계는 보스 부위에 별 모양 폭발을 만들고, 일반 효과의 명중 표현을 260ms까지 유지합니다. 피해 적용 시점은 기존의 180ms 그대로입니다.

모바일은 보드 10×20을 유지하고 아우라·공격을 보드 셀과 예고 UI 밖으로 제한합니다. 효과 감소 옵션은 강한 움직임과 폭발을 줄입니다. 위험 경고 시에는 아우라가 경고를 가리지 않습니다. 시작 도감에 기세 설명·예시를 추가했고, 결과와 로컬 기록에는 최고 기세를 남깁니다.

## 검증

기세 증가·유지·초기화, 발동 이유, 피해량 불변, HUD·도감·결과 연동, 연출 단계와 입자 상한을 자동 검사합니다. 별도 비교에서는 동일 시드와 546개 조작에 대해 이전 버전과 전투 상태가 같음을 확인했습니다. PC와 390px 세로 화면은 테스트용 전투 상태와 고정 프레임으로 연출을 확인했습니다.
