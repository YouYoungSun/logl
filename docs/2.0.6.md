# 2.0.6 — 방어 버프 재충전

- 차단·행 제거는 전투 시작 시 1회 충전, 최대 1회 보유합니다.
- 실제 발동에 성공한 뒤 블록 고정 수로 재충전합니다. 차단 Lv.1/2는 12/10블록, 행 제거 Lv.1/2/3은 12/10/8블록입니다.
- 재충전이 완료되는 고정부터 다시 발동할 수 있습니다. 조건을 만족하지 못하거나 제거할 회색 행이 없으면 충전을 쓰지 않습니다.
- 행 제거는 2줄 이상, 즉 4줄 제거에도 발동합니다. 차단은 기존처럼 공격 예고 01에서 2줄 이상 제거할 때 발동합니다.
- HUD·카드·도감에 재충전 규칙과 남은 블록 수를 표시합니다. 최종 보스 페이즈 전환은 별도 충전을 주지 않습니다.

사용자 요청에 따라 자동 테스트와 플레이 테스트를 실행하지 않고 빌드·배포합니다.
