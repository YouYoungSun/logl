# 2.0.5 — 성공 순간만 강조하는 PC 화면

중앙에 계속 남아 있던 기세 배지와 금빛 구조물이 플레이 시선을 방해한다는 피드백을 반영했습니다. 게이머와 연출 담당은 평소 화면을 비우고 성공 순간에만 큰 표현을 보여주는 방향에 동의했습니다.

- 중앙 고정 기세·콤보 배지를 제거하고 오른쪽 외곽의 공격 예고 아래로 옮겼습니다. 보드와 보스 사이 공격 통로를 비웠습니다.
- 일반 성공 카드는 0.15초 유지한 뒤 0.5초 동안 사라집니다. 승급·반복 방출 카드는 0.2초 유지한 뒤 0.8초 동안 사라집니다.
- 큰 금빛 게이트와 배경 단층은 기세 승급·16/20/24… 반복 방출 때만 0.2초 유지 후 0.9초 동안 페이드아웃합니다. 일반 줄 제거는 이 배경을 재점화하지 않습니다.
- 연속 성공이 기존 효과의 종료 시간을 연장하지 않습니다. 카드 종료 후 0.25초, 큰 배경 종료 후 0.25초의 빈 구간을 둔 뒤 새 성공에 반응합니다. 표시 중의 숫자는 최신 상태를 보여줍니다.
- 작은 하단 HUD에는 실제 기세 수치·단계·콤보를 항상 표시합니다. 작은 충전 슬롯과 실제 4줄 준비 신호, 공격·판재 분리·잔류 균열은 유지했습니다.
- 전투 규칙·기세 누적·피해량·10×20 보드와 모바일 연출은 유지합니다.

자동 검사 86개가 통과했습니다. 페이드 완전 종료, 빠른 연쇄에서 수명 연장 방지, 외곽 위치와 고정 HUD 유지 검사를 포함합니다. PC 브라우저의 테스트 장면에서 등장·페이드 중·종료를 확인했고, 게이머가 코드와 세 장면을 재검토해 통과 평가했습니다. 연속 재생의 실제 체감·음향 청취와는 구분합니다.
