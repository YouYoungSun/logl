# 게이머 관점 이해도 검토와 v0.1.2 수정

검토 대상은 현재 게임의 12개 보상과 6개 위험이다. 다음 버전 계획의 15개 보상이 이미 구현되었다고 가정하지 않았다. 서브에이전트가 실제 설명과 판정을 대조했다. 이는 실제 참가자를 대상으로 한 사용성 테스트는 아니다.

## 결론

몇몇 능력은 설명만으로 이해하기 어렵다. 이름 외에도 선수 지식, 조건의 시점, 실제 소모 시점과 예외가 빠져 있었다. 다음 5개가 가장 문제가 컸다.

| 능력 | 기존 설명의 문제 | 이번 수정 |
|---|---|---|
| 전환 | 연쇄·종료·전하·내림 공식이 한꺼번에 등장 | 3연쇄/4연쇄 종료 시 얻는 양을 먼저 표시. 공식은 예시에 넣음. 다음 15개 재편에서 삭제 추천 유지 |
| 연쇄 증폭 | 19%를 한 번 받는지 단계당 받는지 불명확 | 기본 단계당 15%가 현재 등급의 비율로 바뀐다고 명시. 1/2/3연쇄 배율 예시 |
| 연쇄 유예 | 제거할 때마다 실패 1회가 회복되는 것으로 오해 | 한 연쇄 전체에 딱 1회라고 명시. 제거→실패→제거→실패 예시 |
| 연속 압축 | 바로 다음 블록도 4줄을 지워야 하는 것으로 오해 | 직전 ‘줄 제거 사건’이 기준이라고 설명. 중간 비제거 허용/1줄 제거 미허용을 예시로 비교 |
| 비제거 충전 | 전하의 사용 시점 누락 | 다음 줄 제거 때 모두 소비해 추가 피해를 준다고 명시 |

추가로 ‘고정 피해’는 방어 무시 공격으로 오해할 수 있어 개시의 설명을 바꿨다. 실제로는 방어와 감쇠가 적용된다. 재생에는 회복 주체가 보스라고 명시했고, 수복에는 회색 행만 대상으로 하며 추가 피해가 없다는 설명을 넣었다.

## UI 수정

- 카드 이름 아래에 발동 조건을 짧게 표시한다.
- 예시는 펼쳐 보도록 하고 개조 선택 버튼과 분리한다.
- 기본 용어: 고정, 연쇄, 전하, 높이를 보상/빌드/도움말에서 확인한다.
- 고도/저상을 획득했을 때 보드 옆에 현재 높이, 현재 블록의 고스트 위치에 놓았을 때 높이, 발동 기준을 보여준다.
- 능력의 수치와 판정은 이번 수정에서 바꾸지 않았다. 전환의 구조적 복잡성은 문구 개선만으로 해결되었다고 판단하지 않는다.

## 사망 장면 확인

사망 즉시 보드와 전투 연출을 멈추고 사망 이유를 표시한다. 보드 전체를 흐리지 않아 블록 배치를 볼 수 있다. 새 입력을 하면 기존 결과 화면으로 이동한다. 기록은 사망 순간 한 번 저장한다.

- 생성 막힘: 들어오지 못한 블록과 겹친 위치를 표시한다.
- 상단 초과: 천장 위에 남은 블록의 열을 표시한다.
- 방해 행 상승: 위로 밀려나간 블록의 열을 표시한다.
- 누른 채 유지하던 키, OS 자동 반복, 원래 터치의 해제는 결과 화면으로 넘기는 새 입력이 아니다.
- Tab 이동과 브라우저 단축키는 결과 화면 전환으로 취급하지 않는다.

자동 규칙 검사와 DOM 어댑터/Canvas 검사는 실제 브라우저의 키감과 모바일 배치 확인을 대체하지 않는다. 브라우저 실플레이 확인에는 기존 환경 제약이 남아 있다.
