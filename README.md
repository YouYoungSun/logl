# FAULTLINE / 단층 — ver2 (2.0.6)

떨어지는 블록으로 줄을 지워 보스를 공격하는 10구역 로그라이크입니다. 1~9구역을 깰 때마다 버프와 디버프 한 쌍을 선택합니다. 사망 후에는 1구역부터 새로 시작하거나, 한 구역 전부터 능력을 다시 구성해 재도전할 수 있습니다.

ver2에는 시작 화면의 버프·디버프 도감, 상세 예시, 선택 화면마다 무료 새로고침 1회, 한 공격 안의 회색 행 빈칸 정렬, 최종 보스의 3페이즈 연출과 NEXT 숨김이 추가되었습니다. 2.0.1에서는 공격 중복 카드 두 개를 방해 행 차단·착지 보조로 교체했고, 주기적 증원과 큰 콤보 표시·연쇄 보호/종료 안내를 추가했습니다. 2.0.2에서는 모바일 전용 전투 배치, 커진 보드, 줄 수별 공격 형태와 연쇄 아우라를 보강했습니다. 최신 연출·배치는 `docs/2.0.2.md`, 능력 규칙은 `docs/2.0.1.md`, ver2 기반 변경은 `docs/VER2.md`를 참고하세요.

2.0.3에서는 콤보가 끊겨도 구역을 넘어 쌓이는 **기세**를 추가했습니다. 줄을 지운 고정마다 1씩 쌓이며 1·4·8·12에서 아우라와 공격 연출이 진화합니다. 빌드별 발동 이유, 최고 기세 기록, 확대된 투사체·잔상·폭발·충격파가 추가되었으며 피해량은 변하지 않습니다. 상세 규칙과 예시는 `docs/2.0.3.md`를 참고하세요.

2.0.4는 **PC 전투 연출을 재설계**했습니다. 보드 옆 큰 기세 배지와 별도 콤보, 단계별로 넓어지는 전장 구조, 실제 삭제 행에서 이어지는 공격, 줄 수별 관통·합류·압축, 보스 판재 분리와 잔류 균열을 추가했습니다. OVERDRIVE 이후에도 네 번의 성공마다 충전 장치가 방출되며, PC 표시 체력은 명중 순간에 줄어듭니다. 모바일은 기존 배치와 연출을 유지합니다. 변경 명세와 검증 범위는 `docs/2.0.4.md`에 있습니다.

2.0.5에서는 PC 중앙의 큰 기세·콤보 배지를 오른쪽 외곽으로 옮기고, 성공 후 페이드아웃하도록 바꿨습니다. 금빛 게이트·대형 배경 균열도 승급과 반복 방출 때만 잠깐 나타났다 사라집니다. 작은 고정 HUD에서 기세·단계·콤보를 항상 확인할 수 있습니다. [표시 시간과 변경 내용](docs/2.0.5.md)을 참고하세요.

2.0.6에서는 차단·행 제거를 재충전형으로 변경했습니다. 실제 사용 후 블록을 놓아 다시 충전하며, 행 제거는 4줄에도 발동합니다. 차단은 레벨별 12/10블록, 행 제거는 12/10/8블록마다 재충전됩니다. 이번 업데이트는 사용자 요청으로 테스트를 실행하지 않았습니다.

## 바로 실행하기

1. ZIP을 풀고 안의 `loglike` 폴더를 원하는 위치로 옮깁니다. 예: `D:\loglike`.
2. **`play.html`을 Chrome 또는 Edge에서 열면 바로 플레이할 수 있습니다.** 인터넷, Node, 설치 명령, 계정, API 키가 필요 없습니다.
3. 데스크톱 키보드와 모바일 터치 조작을 지원합니다. 세로 휴대폰은 보스·공격 예고를 위로 옮기고 보드를 크게 표시하는 전용 배치를 사용합니다.

`play.html`은 소스에서 생성한 휴대용 파일입니다. 소스를 수정한 뒤에는 아래 빌드를 다시 실행해야 반영됩니다. 브라우저 정책에 따라 파일에서 연 기록은 저장되지 않을 수 있으므로, 개발과 안정적인 로컬 기록에는 아래 서버 실행을 권장합니다.

## 소스 실행 / 수정

Node.js 20 이상이 설치되어 있으면 `start.bat`을 실행하세요. 또는 프로젝트 폴더에서:

```bash
npm run dev
```

브라우저가 자동으로 열립니다. 자동 열기가 안 되면 터미널에 출력된 `http://localhost:5173`에 접속하세요. 포트가 사용 중이면 `npm start -- --port 5174`로 실행할 수 있습니다. 실행 중인 터미널을 닫으면 서버가 종료됩니다.

**런타임 외부 패키지가 없어 `npm install`은 필요하지 않습니다.**

```bash
npm test
npm run build
```

빌드는 `dist/`와 루트의 `play.html`을 새로 만듭니다. `dist/`에는 정적 배포 파일이 들어갑니다.

## 조작

| 키 | 동작 |
|---|---|
| ← / → 또는 A / D | 이동, 누르고 있으면 반복 이동 |
| ↓ 또는 S | 빠른 낙하 |
| X / ↑ | 시계 방향 회전 |
| Z | 반시계 방향 회전 |
| Space | 즉시 낙하 및 고정 |
| C / Shift | 홀드, 다음 고정 전까지 재사용 불가 |
| P / Esc | 일시정지 / 재개 |
| 1 / 2 / 3 | 승리 후 선택지 선택 |

사망하면 즉시 결과 메뉴로 이동하지 않습니다. 보드와 사망 원인이 멈춘 상태에서 상단의 붉은 표시를 확인할 수 있습니다. 새 클릭 또는 키 입력 후 결과 메뉴로 넘어갑니다. 죽을 때 누르던 키의 자동 반복과 터치 해제로는 넘어가지 않습니다.

시작 화면의 도감과 보상·빌드 메뉴에는 발동 조건, 예시와 기본 용어 설명이 있습니다. 고층/저층 강화를 얻으면 보드 옆에 현재 높이와 다음 배치 후 높이, 발동 기준을 표시합니다.

7-bag, SRS 회전, 고스트, 다음 블록 5개, 500ms 기본 고정 유예와 최대 15회 유예 초기화를 지원합니다. 탭을 떠나면 전투가 일시정지됩니다. 소리와 효과 감소 옵션은 상단에서 바꿀 수 있습니다.

## 전투와 누적 선택

- 1/2/3/4줄 기본 피해는 10/24/42/64입니다. 연속으로 줄을 지우는 고정은 연쇄 피해를 높입니다. 기본적으로 줄을 못 지우면 연쇄가 끊깁니다.
- 보스 공격 카운트는 **시간 대신 고정한 블록 수**로 줄어듭니다. 낙하 속도는 별도로 올라갑니다.
- 공격할 방해 행과 구멍을 미리 표시합니다. 대응 패턴에서는 마지막 3고정에 총 2줄을 지우면 예정 공격을 1행 줄입니다. 최소 1행은 남습니다.
- 방어 패턴은 일반 피해 ×0.65, 노출 창 피해 ×1.35입니다. 조급 부담은 공격 주기와 노출 비율을 함께 바꿉니다.
- 스테이지를 클리어하면 보드와 회색 방해 행, 홀드, 다음 블록, 연쇄·전하와 전투별 사용 횟수는 초기화됩니다. 다음 전투는 빈 보드와 새 7-bag로 시작합니다. 누적 강화·부담, 선택 이력, 기세와 런 전체 통계는 유지됩니다.
- 1~9구역 승리마다 3가지 **버프 + 디버프** 묶음 중 하나를 선택합니다. 이전 효과를 대체하지 않습니다. 각 화면에서 선택지 전체를 무료로 한 번 새로고침할 수 있습니다. 방해 행 정리는 새 전투에서 방해 행이 생긴 뒤 조건을 만족할 때 작동합니다.
- 10구역은 별도 형태의 최종 보스이며, 체력 70%와 35%에서 다음 페이즈를 예약합니다. 진행 중인 공격 주기는 끝까지 유지됩니다. 10구역 뒤에는 보상 선택이 없습니다.
- 사망 후 1구역부터 재시작하거나, 사망한 구역보다 하나 낮은 구역에서 보조 재도전을 할 수 있습니다. 예를 들어 5구역 사망 후 4구역을 선택하면 세 번의 버프·디버프 선택을 마친 뒤 빈 보드에서 시작합니다. 기존 능력은 이어받지 않습니다.

자세한 스테이지 수치, 타격 타임라인, 밸런스 검토는 `docs/IMPLEMENTATION.md`에 있습니다.

## 기록과 시드

기록은 브라우저 `localStorage`에 정규·중간 재도전별 최대 20개씩 저장합니다. 같은 규칙 버전에서 돌파 구역, 현재 보스 진행률, 적은 고정 수, 짧은 전투 시간 순으로 정렬합니다. 서버, 계정, DB와 전역 랭킹은 연결하지 않았습니다. 이 로컬 기록은 사용자가 변경할 수 있으므로 온라인 경쟁 랭킹의 검증 수단이 아닙니다.

시드는 블록 / 보상 / 방해 행 난수 흐름을 분리해 고정합니다. 같은 시드의 전투 결과는 조작과 선택에 따라 달라집니다. 브라우저와 `file:` / `localhost` / 배포 주소는 서로 다른 기록 저장소를 사용합니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `src/core.mjs` | 보드, 조작, 피해, 10구역, 선택, 승패 판정 |
| `src/main.mjs` | 고정 시간 루프, 입력, Canvas 화면, 메뉴, 로컬 기록 |
| `src/boss-art.mjs` | 움직이는 기하학 보스와 최종 보스 원본 아트 |
| `src/fx.mjs` | 삭제 행 응축, 투사체, 탄착, 반동, 파편 |
| `src/death-review.mjs` | 사망 장면을 넘기는 새 입력과 눌린 입력 구분 |
| `src/audio.mjs` | Web Audio로 합성한 효과음 |
| `scripts/build.mjs` | 정적 배포 파일 및 휴대용 HTML 생성 |
| `tests/` | 외부 패키지 없는 Node 규칙/연출 테스트 |

전투 보스는 Canvas에서 부품과 코어를 그립니다. 시작 화면에는 생성한 키 아트 `assets/faultline-ver2.png`를 사용하며, 휴대용 HTML에는 이미지까지 내장됩니다. 외부 폰트·음원·추적 코드·CDN은 사용하지 않습니다.

## Git / Vercel로 옮길 때

`loglike` 폴더의 소스를 Git 저장소에 올리면 됩니다. Vercel용 `vercel.json`이 포함되어 있습니다. 프로젝트 루트는 `package.json`이 있는 `loglike` 폴더, 빌드 명령은 `npm run build`, 출력 폴더는 `dist`, 프레임워크는 Other입니다. 환경변수는 없습니다. 푸시와 실제 호스팅 배포 상태는 각각 별도로 확인하세요.

## 검증 범위

Node 규칙 테스트와 연출 테스트를 포함했습니다. 별도 개발 검사에서는 실제 `main.mjs` 루프와 Canvas 렌더러를 DOM 테스트 어댑터에 연결하여 이동·회전·홀드·낙하·일시정지, 10회 승리와 9번 누적 선택, 승리·재시작·상단 사망·기록을 확인했습니다. 타격 전후 Canvas 출력도 확인했습니다. 10구역 상태 전환 검사는 테스트용 보드와 HP를 주입한 검사이며, 정상 난이도로 10구역을 완주했다는 의미는 아닙니다.

ver2에서는 실제 브라우저로 PC·390px 모바일 도감과 시작 화면, 사망→이전 구역 재구성→전투 시작, 최종 보스 일식의 NEXT 숨김을 확인했습니다. 페이즈·사망 검사는 테스트 상태를 사용했습니다. 자동 규칙 검증과 화면 검증은 정상 플레이 완주율·빌드별 승률 측정을 대체하지 않습니다. 소리의 청취 품질과 장기적인 난이도는 별도 플레이 테스트가 필요합니다.
