# FAULTLINE / 단층 — v0.1.1

떨어지는 블록으로 줄을 지워 보스를 공격하는 10구역 로그라이크입니다. 1~9구역을 깰 때마다 강화와 지속 부담 한 쌍을 선택합니다. 모든 선택은 누적되며, 죽으면 빈 보드와 무강화 상태에서 다시 시작합니다.

## 바로 실행하기

1. ZIP을 풀고 안의 `loglike` 폴더를 원하는 위치로 옮깁니다. 예: `D:\loglike`.
2. **`play.html`을 Chrome 또는 Edge에서 열면 바로 플레이할 수 있습니다.** 인터넷, Node, 설치 명령, 계정, API 키가 필요 없습니다.
3. 기본 환경은 데스크톱 키보드입니다. 작은 화면용 터치 버튼도 있지만, 세로 휴대폰에서는 보드와 예고 글씨가 작습니다.

`play.html`은 소스에서 생성한 휴대용 파일입니다. 소스를 수정한 뒤에는 아래 빌드를 다시 실행해야 반영됩니다. 브라우저 정책에 따라 파일에서 연 기록은 저장되지 않을 수 있으므로, 개발과 안정적인 로컬 기록에는 아래 서버 실행을 권장합니다.

## 소스 실행 / 수정

Node.js 20 이상이 설치되어 있으면 `start.bat`을 실행하세요. 또는 프로젝트 폴더에서:

```bash
npm run dev
```

브라우저가 자동으로 열립니다. 자동 열기가 안 되면 터미널에 출력된 `http://localhost:5173`에 접속하세요. 포트가 사용 중이면 `npm start -- --port 5174`로 실행할 수 있습니다. 실행 중인 터미널을 닫으면 서버가 종료됩니다.

**런타임 외부 패키지가 없어 `npm install`은 필요하지 않습니다.**

```bash
npm test
npm run build
```

빌드는 `dist/`와 루트의 `play.html`을 새로 만듭니다. `dist/`에는 정적 배포 파일이 들어갑니다.

## 조작

| 키 | 동작 |
|---|---|
| ← / → 또는 A / D | 이동, 누르고 있으면 반복 이동 |
| ↓ 또는 S | 빠른 낙하 |
| X / ↑ | 시계 방향 회전 |
| Z | 반시계 방향 회전 |
| Space | 즉시 낙하 및 고정 |
| C / Shift | 홀드, 다음 고정 전까지 재사용 불가 |
| P / Esc | 일시정지 / 재개 |
| 1 / 2 / 3 | 승리 후 선택지 선택 |

7-bag, SRS 회전, 고스트, 다음 블록 5개, 500ms 기본 고정 유예와 최대 15회 유예 초기화를 지원합니다. 탭을 떠나면 전투가 일시정지됩니다. 소리와 효과 감소 옵션은 상단에서 바꿀 수 있습니다.

## 전투와 누적 선택

- 1/2/3/4줄 기본 피해는 10/24/42/64입니다. 연속으로 줄을 지우는 고정은 연쇄 피해를 높입니다. 기본적으로 줄을 못 지우면 연쇄가 끊깁니다.
- 보스 공격 카운트는 **시간 대신 고정한 블록 수**로 줄어듭니다. 낙하 속도는 별도로 올라갑니다.
- 공격할 방해 행과 구멍을 미리 표시합니다. 대응 패턴에서는 마지막 3고정에 총 2줄을 지우면 예정 공격을 1행 줄입니다. 최소 1행은 남습니다.
- 방어 패턴은 일반 피해 ×0.65, 노출 창 피해 ×1.35입니다. 조급 부담은 공격 주기와 노출 비율을 함께 바꿉니다.
- 스테이지를 클리어하면 보드와 회색 방해 행, 홀드, 다음 블록, 연쇄·전하와 전투별 사용 횟수는 초기화됩니다. 다음 전투는 빈 보드와 새 7-bag로 시작합니다. 누적 강화·부담, 선택 이력과 런 전체 통계는 유지됩니다.
- 1~9구역 승리마다 3가지 **강화 + 부담** 묶음 중 하나를 선택합니다. 이전 효과를 대체하지 않습니다. 재선택은 없습니다. 수복은 새 전투에서 방해 행이 생긴 뒤 조건을 만족할 때 작동합니다.
- 10구역은 별도 형태의 최종 보스이며, 체력 70%와 35%에서 다음 페이즈를 예약합니다. 진행 중인 공격 주기는 끝까지 유지됩니다. 10구역 뒤에는 보상 선택이 없습니다.
- 상단 막힘 / 정리 후 상단 초과 / 방해 행 상승 중 상단 넘침으로 사망하면 런이 종료됩니다. 영구 능력치 성장과 체크포인트는 없습니다.

자세한 스테이지 수치, 타격 타임라인, 밸런스 검토는 `docs/IMPLEMENTATION.md`에 있습니다.

## 기록과 시드

기록은 브라우저 `localStorage`에 최대 20개 저장합니다. 같은 규칙 버전에서 돌파 구역, 현재 보스 진행률, 적은 고정 수, 짧은 전투 시간 순으로 정렬합니다. 서버, 계정, DB와 전역 랭킹은 연결하지 않았습니다. 이 로컬 기록은 사용자가 변경할 수 있으므로 온라인 경쟁 랭킹의 검증 수단이 아닙니다.

시드는 블록 / 보상 / 방해 행 난수 흐름을 분리해 고정합니다. 같은 시드의 전투 결과는 조작과 선택에 따라 달라집니다. 브라우저와 `file:` / `localhost` / 배포 주소는 서로 다른 기록 저장소를 사용합니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `src/core.mjs` | 보드, 조작, 피해, 10구역, 선택, 승패 판정 |
| `src/main.mjs` | 고정 시간 루프, 입력, Canvas 화면, 메뉴, 로컬 기록 |
| `src/boss-art.mjs` | 움직이는 기하학 보스와 최종 보스 원본 아트 |
| `src/fx.mjs` | 삭제 행 응축, 투사체, 탄착, 반동, 파편 |
| `src/audio.mjs` | Web Audio로 합성한 효과음 |
| `scripts/build.mjs` | 정적 배포 파일 및 휴대용 HTML 생성 |
| `tests/` | 외부 패키지 없는 Node 규칙/연출 테스트 |

보스는 PNG 한 장을 흔드는 방식이 아니라 Canvas에서 판별 가능한 부품과 코어를 그립니다. 별도 다운로드 이미지, 폰트, 음원, 추적 코드 또는 CDN을 사용하지 않습니다.

## Git / Vercel로 옮길 때

`loglike` 폴더의 소스를 Git 저장소에 올리면 됩니다. Vercel용 `vercel.json`이 포함되어 있습니다. 프로젝트 루트는 `package.json`이 있는 `loglike` 폴더, 빌드 명령은 `npm run build`, 출력 폴더는 `dist`, 프레임워크는 Other입니다. 환경변수는 없습니다. 이번 작업에서 Git 원격 저장소나 Vercel / Sites에는 연결하거나 배포하지 않았습니다.

## 검증 범위

Node 규칙 테스트와 연출 테스트를 포함했습니다. 별도 개발 검사에서는 실제 `main.mjs` 루프와 Canvas 렌더러를 DOM 테스트 어댑터에 연결하여 이동·회전·홀드·낙하·일시정지, 10회 승리와 9번 누적 선택, 승리·재시작·상단 사망·기록을 확인했습니다. 타격 전후 Canvas 출력도 확인했습니다. 10구역 상태 전환 검사는 테스트용 보드와 HP를 주입한 검사이며, 정상 난이도로 10구역을 완주했다는 의미는 아닙니다.

**실제 브라우저에서의 키감, CSS 배치, 모바일 조작, 소리 청취 검증은 이 작업 환경의 로컬 브라우저 연결 제한으로 완료하지 못했습니다.** 자동 규칙 검증은 실제 플레이 난이도 검증과 다릅니다. 첫 플레이 가능한 버전이며, 숙련자 완주율이나 빌드별 승률을 측정한 최종 밸런스는 아닙니다.
